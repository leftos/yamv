# Glossary

- **Activation gate**: holds an `activate` request that arrives before the main window exists and delivers it once the window is shown, coalescing duplicates.
- **App default**: the content width a document uses when no folder at or above it has its own width; set from the popover's All documents segment ([content-width.md](design/content-width.md)).
- **Appearance**: Match system, Light or Dark — which half of the current theme family is shown.
- **Asset cache**: the versioned folder under the local app-data dir (`YAMV/web/{assembly version id}/`) that the document page's template, CSS, JS, fonts and vendored libraries are extracted to, so the page loads over `file://`.
- **Bad streak**: the run of theme reloads during which the theme in use has no valid file (invalid, deleted or renamed); `ThemeBridge` logs one warning for it, and one line when the file loads again.
- **Chrome**: the app's own UI around the document (title bar, sidebar tree, dialogs), drawn with Avalonia from the theme's chrome tokens, as opposed to the document page.
- **Content width**: how wide the document's text column is: a px text measure from 480, or Full; set per folder or for all documents ([content-width.md](design/content-width.md)).
- **Debounce**: waiting for a burst of events to go quiet before acting once: `DocumentFileWatcher` reports a batch 150 ms after the last event naming an open document, at most 1 s after the first; the session saver and the theme folder watcher wait 500 ms and 300 ms the same way.
- **Disk-change bar**: the bar under the theme settings window's title bar that says the selected theme's file changed on disk while unsaved edits are open, with Reload and Keep mine; it takes the warning colours when the file no longer parses ([look.md](design/look.md)).
- **Document surface**: what the window logic sees of the document page (`IDocumentSurface`, implemented by `DocumentView`); tests substitute a fake.
- **Edit as text**: opening a user theme's `.json` file in the app the system associates with it (`IFileActions.OpenWithDefaultApp`, built by `OpenFileCommand`).
- **First-stamp window**: the short time in which a change to a document in a polled folder is missed, between a subscriber's read of a newly opened document and the watcher's first length and write-time stamp of it (`DocumentFileWatcher`); a window calls `SetPaths` before reading to keep it to one thread-pool dispatch.
- **Grace**: the 500 ms in which a shown document whose file went missing keeps its page before the missing pane shows, so an editor that saves by deleting and re-creating the file never flashes it; the file is read once more when it ends (`DocumentWindowViewModel`).
- **Grace period**: the 300 ms after framework initialization on macOS during which launch-time file opens may arrive, before the main window is created.
- **Group**: a top-level node of the sidebar tree, one per group root: a git repo or a folder.
- **Group root**: the folder a document is grouped under in the tree: its git work-tree root, or its parent folder when it is not in a repo.
- **Half**: the light or dark part of a theme family: its `light` or `dark` object, with that half's tokens and css ([themes.md](design/themes.md)).
- **Harness window**: the development window (`HarnessWindow`) that hosts a bare `DocumentView` with `--theme`, `--find`, `--scroll` and similar switches; opened instead of the main window when `YAMV_DEV_HARNESS=1`.
- **Import notice**: the modal an Import shows before copying a theme file, with a card for the file (name, author, halves, whether it has css, its path, its errors and warnings) and the warning about css that loads from the web; the card is read by `ThemeCatalog.Inspect` into a `ThemeInspection` ([themes.md](design/themes.md)).
- **Inherited value**: a token's value in the token editor when the tab sets none: shown grey, taken from Shared or the defaults (on the Shared tab, from the defaults). Setting it, even to the same value, makes it set; ↺ removes a set value.
- **Last good version**: the version of the theme in use that `ThemeBridge` keeps applying while its file is invalid or gone, even when a built-in has the same id.
- **Launch arbiter**: the Core state machine that turns framework, file-open and Dock/activate events of a macOS launch into what it decides: a main window, a viewer window, or activating the main window.
- **Link policy**: the Core rule (`LinkPolicy.Decide`) that turns a clicked link, or a dropped file's path, into a `LinkDecision`: open externally, open as a document, open with the default app, ask first, or ignore.
- **Live reload**: re-reading and redrawing an open document when its file changes on disk; Core's `DocumentFileWatcher` reports which open documents may have changed, watching each folder once and polling a folder that cannot be watched, where only a changed length or write time counts.
- **Main instance**: the one YAMV process started with no file arguments. It remembers its open documents between runs; a second no-arg launch brings it to the front and exits.
- **Main-instance pid file**: `main.pid` beside `main.lock`, written by the main instance with its pid and process start time so a second launch can tell the recorded process is still the main instance; deleted when the main instance stops answering, as its main window closes, before the final session save.
- **Missing document**: an open document whose file no longer exists, or a path a viewer launch named that does not exist; it stays in the tree, greyed, until removed or until the file comes back.
- **Missing row**: the greyed "Missing on disk" row the theme settings window keeps for the theme in use whose file was deleted or renamed outside the app, in its last loaded version; only Save (which writes the file again) and Revert are on ([look.md](design/look.md)).
- **Open with registration**: what `yamv --register` writes on Windows so YAMV appears in Explorer's Open with for `.md` and `.markdown`: the `YAMV.Markdown` ProgID, an `OpenWithProgids` entry per extension and the `Applications\yamv.exe` key, all under the current user. It never sets the default handler.
- **Persist**: a window's flag saying its documents, selection and layout are saved to the session file; true only for the main instance's window.
- **Pin**: a view at the very top (or very bottom) of a document when it reloads stays at the top (or follows text appended at the bottom), instead of keeping a block in place.
- **Popover**: the content-width control the title bar's ⟷ button opens: a native Avalonia Popup, which is a window of its own so it can sit over the web view ([content-width.md](design/content-width.md)).
- **ProgID**: a Windows programmatic identifier, a registry key naming a file type and how to open it; YAMV's is `YAMV.Markdown`.
- **Reveal**: showing a path in the platform's file manager from a tree menu: a file is shown selected in Explorer or Finder, a folder or group root is opened, and a missing document opens its nearest folder that still exists (`RevealCommand`).
- **Saved for**: the content-width popover's segmented control: the folders a width can be saved for, deepest first, then All documents (`WidthScopes`, [content-width.md](design/content-width.md)).
- **Scroll anchor**: where a document's view stands as a top-level block and a place in it: the block's `data-line` source line and the fraction of its height above the top of the view (`ScrollAnchor`); it restores the view on a tab switch back and a session restore, and is saved in `session.json`.
- **Second launch**: a no-argument `yamv` start while another process holds the main-instance lock; it asks the main instance to come forward and exits 0, brings that window forward itself and exits 1 when the signal fails, or, with no pid file, waits up to 5 s for the lock and starts as the main instance (`SecondLaunch`).
- **Settings file**: `settings.json`, the app-wide settings shared by every window and process (`SettingsStore`, saved off the UI thread by `SettingsWriter`, watched by `SettingsWatcher`: an edit made outside the app is applied to every window and never saved back); widths stay in `widths.json`, and the main window's documents and layout in `session.json`.
- **Sidebar**: the pane on the window's right holding the tree of open documents.
- **Source** (of a width): the folder a document's width is inherited from, or the app default; the popover opens with it selected and the Ctrl+[ and Ctrl+] steps edit it ([content-width.md](design/content-width.md)).
- **Staging**: the hidden element the page builds a reloaded document in while the old page stays on screen; it is swapped in in one step once built (`yamv.js`).
- **Text measure**: the width in px of the document's text lines, which is what a stored content width means; the column adds 44 px of side padding on each side.
- **Text space**: the room a pane leaves for the document's text: the pane width less the page's 88 px of side padding (`ContentWidth.TextSpace`); a content width is compared against it ([content-width.md](design/content-width.md)).
- **Theme family**: one `.yamv-theme.json` file, holding a light half, a dark half or both ([themes.md](design/themes.md)).
- **Toast**: a short-lived card at the bottom of the document pane reporting a failed or refused operation the user started (`ToastCenter`, shown through `IToasts`); a repeat of its text counts "×N" and restarts its 5 s fade, the fade pauses while the window is inactive or minimized, and at most three are up ([look.md](design/look.md)).
- **Token**: a named theme value (a colour, font, size) that drives both the document page (as a `--yamv-*` CSS property) and the app chrome.
- **Tree order**: the order documents appear in the sidebar tree (groups, then folders before files, case-insensitively), which Close, Ctrl+Tab and Ctrl+Shift+Tab follow; it differs from the order documents were opened.
- **Unreadable document**: an open document whose file exists but cannot be read (locked by another program, or access denied); the window shows the can't-read pane (`UnreadableDocumentPane`) in place of the page, and the state clears on a successful read, a selection change, or the file going missing.
- **Viewable type**: a file type on `LinkPolicy.ViewableExtensions` (images, audio, video, PDF, CSV, JSON, XML, YAML, logs) that a link opens in the default app without asking, when both the link's name and its resolved target are on the list; any other type, or a folder, asks first.
- **Viewer instance**: a YAMV window started with file arguments (or, on macOS, a Finder open); on Windows its own process. It shows only those files and is non-persisting: it never writes `session.json`, has no saved layout, shows the tree only with 2+ documents, closes when its last document closes, and reads no session file: its theme comes from the settings file (`settings.json`).
- **WebView2 user-data folder**: where WebView2 keeps the document page's browser profile on Windows: `%LOCALAPPDATA%\YAMV\webview2`, shared by every YAMV process, or the folder `WEBVIEW2_USER_DATA_FOLDER` names when set (each hidden run gets its own).
- **Working copy**: the theme the theme settings window edits, a copy of the selected theme that edits change until Save or Revert; the token rows and the preview (`PreviewTheme`) read it, while the window and the app keep the saved theme.
- **Yours**: the user-themes section of the theme list in the theme settings window, below Built-in.
