YAMV-74: the content-width slider when the stored width is wider than the window

A document in yaat takes the app default, 800 px. The window's pane is 800 px, so its text space (pane minus the 88 px of side padding) is 712 px and the page draws the text at 712. Today the slider runs 480 → 712 and snaps to Full in its last 5%, so its last px value is 700 (ContentWidth.FromSlider): once the user drags, 800 cannot be picked again in this window.

Each lane is the popover at its real size (1:1) in a crop of the window's right end, over the tree; state 1 is the popover as it opens, state 2 after a drag left and back to the right end, released there. Every UI colour is a Studio token. Orange marks are annotations, not UI.
