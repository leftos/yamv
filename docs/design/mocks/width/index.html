YAMV: where the content-width slider lives

The slider runs from 480 px up to the pane's width and snaps to Full at the end. The width belongs to a folder, and a document uses the nearest folder above it that has one, else the app default. Each option is shown with the slider set to 760 px.

A · Title-bar button + popover

A ⟷ button in the title bar opens a popover with the slider, the folder it saves to, and Reset / Make default. Ctrl+[ and Ctrl+] step the width.
