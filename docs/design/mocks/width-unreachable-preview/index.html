YAMV-56: previewing a width that can't reach the document

docs/look.md is open in the yamv group. Its folder docs holds its own 760 px, so when the user picks yamv (repo) in the ⟷ popover and drags the slider to 600 px, look.md would not move. Ruled: the pane shows an example document at the dragged width for a while, and a small toast says why the change won't reach look.md.

Each lane is a Studio dark main window drawn at its real size and scaled down: first mid-drag, larger, then a row of moments left to right in time. The last section shows the same mid-drag moment in Studio light. Lanes differ in what the example says, how it is marked as an example, when it appears and goes back, and the toast's words and place. The toast is the approved card with an accent info mark in place of the warning mark, since nothing failed.

Recommended: lane B. The example sits on a sheet over the chrome colour, so it can't be taken for look.md even at a glance, and it reads in plain words about what you are setting. It stays a moment after you let go, so you see the width you saved instead of a flash, then hands the page back by itself. The toast stays in the bottom centre, where every other toast appears.
