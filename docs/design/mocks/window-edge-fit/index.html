YAMV-100: where a window lands when it is pushed back on screen

When YAMV reopens a window whose saved place hangs off a screen edge, it moves the window back onto the screen. This page shows where the window ends up in each lane: pushed into the bottom-right corner, then into the top-left corner. Each corner is shown once at true size and in close-up, where every square is one screen pixel. The theme is Studio dark on a plain dark desktop.

Recommended: B, frame flush. The window sits where Windows itself puts a window you snap into a corner: its thin outline runs along the screen edge and the top of the taskbar. A window you place yourself and one YAMV moves back look the same, and none of the window spills onto a screen next to it.
