YAMV-54 · How does an elevated YAMV say so in its title bars?

An elevated instance shows “Administrator” in the title bar of every one of its windows, so it is clear why two YAMV apps can be open at once. Three ways to draw it, each in Studio light and dark. Every bar is drawn at 1:1 (760 px wide; the theme settings window is 980 px wide by default, cut here), with a 200% detail of the document bar under each lane.

Each lane shows the three bars an elevated instance has: a main window with README.md in yamv / docs, the empty main window (its bar reads “YAMV”, ⟷ is off), and the theme settings window (its bar reads “Themes” then the theme and the half shown; close button only).
