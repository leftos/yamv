YAMV app icon: three options

Each option is one 1024 px master on the macOS Big Sur grid (an 824 px rounded body, 100 px margin). The sizes row is that master rasterized at 256, 64, 32 and 16 px, then the 16 px icon magnified six times, for the macOS art and for the Windows art. Windows uses the same art with the body cropped to fill the square (viewBox="100 100 824 824"), so the title bar and taskbar below show that crop. Studio light palette: accent #0969da, accent-soft #b6d4f5, line #d8dee4.

Amd monogram

The accent rounded square from the chrome mock, carrying a bold white md in JetBrains Mono ExtraBold (outlined to paths), letters pulled together. The same mark the empty state draws dashed, made solid. Master: option-a.svg.
