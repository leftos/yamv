YAMV: live reload, what does the window show while a saved page renders?

When the open file is saved, the page gets the new HTML and renders it again; math (KaTeX) and Mermaid diagrams render after the HTML is in. Today the document is hidden for that whole render (yamv.js:300 adds yamv-pending, :331 removes it; yamv.css:77 is visibility: hidden). The other way keeps the old page up until the new one is done, then swaps in one frame.

Each window is a Studio main window, 700 × 420, shown at 90%. The live rows loop at real speed: the file is saved, the render takes 400 ms (a typical Mermaid render), then the new page shows; each loop saves twice, so every change you see is a save. The orange bar on the timeline is now. Orange marks are annotations, not UI: the dashed box marks the line the save changed.
